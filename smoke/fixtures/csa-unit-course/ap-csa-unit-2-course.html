What you’ll learn in Unit 2
  • Write boolean expressions using relational and logical operators
  • Use if, if-else, and if-else-if statements to control program flow
  • Build while and for loops to repeat code efficiently
  • Implement selection and iteration algorithms (accumulator, counter, sentinel)
  • Trace and debug complex control flow including nested structures
