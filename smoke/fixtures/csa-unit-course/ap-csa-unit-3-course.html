What You'll Master in Unit 3
  • Apply abstraction to identify the right attributes and behaviors for any class
  • Write constructors, accessors, and mutators following AP exam conventions
  • Explain pass-by-value for primitives vs. reference semantics for objects
  • Use static variables and methods correctly (and avoid the classic compile errors)
  • Resolve variable shadowing with this in constructors and methods
  • Predict output and spot bugs in class-design code
