What you’ll learn in Unit 1
  • The difference between an algorithm and a program, and how Java code compiles and runs
  • How to declare and use primitive types (int, double, boolean) and variables
  • How to write arithmetic expressions, handle integer division and casting, and avoid overflow
  • How to call built-in class methods on Math and String using API documentation
  • How to create objects using constructors and call instance methods on them
