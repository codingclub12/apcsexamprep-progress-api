Real or Fake? Four Wi-Fi Login Pages

You just walked into Sunshine Coffee. The sign at the register says the network is Sunshine Coffee Wi-Fi. You connect, and a login page pops up. Below are four versions of that page. Only one is the shop's real page.

For each page: vote REAL or FAKE, then name the one thing that gave it away.

Look at three places: the network name, the web address, and what the page asks you to type.

Teacher key (open after the vote)
PageVerdictThe giveaway
ARealThe network name matches the sign letter for letter, the address is the shop's own domain, and the page asks only for agreement to the terms. Nothing to steal.
BFakeCertificate warning and "Not secure". The address looks right, which is the trap. The network name is also off by one character (WiFi, no hyphen), and a coffee shop has no reason to want your email password.
CFakeDomain mismatch. The padlock is real, but it only proves the connection to free-hotspot-login.example is encrypted. It says nothing about whether that site belongs to Sunshine Coffee.
DFakeWrong network ("Guest Wi-Fi" is the one Jamie joined in Scenario 1C) and it asks for a social media password. This is the Day 3 Client 1 case.

Point to land before moving on: none of these checks happens after you type a password. The name check comes before you connect, and the "what is it asking for" check comes before you type. A padlock alone settles nothing.
