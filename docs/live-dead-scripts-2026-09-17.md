## A page slug is interpolated into a function NAME (19 pages)

The generator that built these pages wrote `function runCode_apcsa-accessmut_1()`
and `function mcqAnswer_apcsa-accessmut_1(...)`. A hyphen is not valid in a
JavaScript identifier, it parses as minus, so every one of these blocks is a
SyntaxError and neither the Run button nor the MCQ answer handler exists.
The fix is mechanical: hyphens to underscores inside identifiers only.

## Missing commas between ANSWERS entries (9 pages)

An eight entry `ANSWERS` object with every comma between entries absent, so the
whole block is a SyntaxError and every question on the page is dead. Seven
missing commas per page, not one: whatever built it joined entries on "\n"
instead of ",\n". `scripts/fix-2d-neighbors-commas.js` repairs this shape and
is already proven on one of them.
