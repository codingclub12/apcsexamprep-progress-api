The four course hub pages: audit and a better setup

AP CSA, AP CSP, AP Cybersecurity and AP Networking course pages. Measured live on 2026-09-25. Board #426, related #419 and #151.

Should the hero card go the full width of the screen? The background band should. The text should not.

Run the navy band edge to edge, the way the nav and the new homepage already do, and keep the heading, buttons and cards inside the same 1200px column the nav uses. Text stretched across a 1920px screen is hard to read. The hero should also get shorter. Today it is 440 to 660px tall on a desktop, and on a phone the first button is below the first screen on three of the four.

Should these pages be updated? Yes, and some of it is wrong facts rather than style.

The CSA hub tells students Unit 3 is about 30% of the exam (the CED says 10 to 18%) and Unit 4 is about 25% (the CED says 30 to 40%). The 54.5% score claim you took out of the theme this morning is still in the CSA page body in eight places, meta description included. The Cyber hub still says 250+ practice questions and lists a "40 MCQ + 3 FRQ" practice exam. The Networking hub has no hero at all, and its body text renders in Times New Roman.

Is there a smarter way to set them up? One shared hub template in the theme, with the course facts in one place.

Right now each hub is a hand-built page body with its own hero, fonts, colours and 4 to 27KB of inline CSS, so they look like four different sites and their facts drift apart. A page.course-hub template would draw the hero, the Course and Exam prep switch, the unit cards, the links to the other courses and the structured data once for all four. The per-course writing stays in the page body. Mockup below.

The proposal: one hub template

Why a template instead of editing four page bodies

  1. A page body cannot go full width cleanly. The theme caps page content at 1500px and puts the body in a 1000px column. The homepage got out of that at the section level (its :has(#apcs-home) rule). A body can only fake it with a 100vw trick, which on Windows adds a sideways scrollbar to every hub. A section does it the same way the homepage does.
  2. The facts stop drifting. The CSA weightings are wrong because four hand-built pages each carry their own copy of unit counts, exam dates and weights. With one data snippet feeding the hero, the unit cards and the structured data, a number is written once. The homepage cards could read the same snippet later.
  3. It removes the hidden H1 and the contact form on these four pages only. Both come from the default page template. A hub template leaves them out, without touching the 1,300 other pages that use the default.
  4. It is cheap to try. Adding a template changes nothing on the live site until a page is pointed at it. Each hub is switched by its own one-row Matrixify sheet (Template Suffix plus a body with the old hero removed), one course at a time, and switched back the same way.

SEO and internal linking, specifically

  • Titles, set in each page's SEO title field so the theme stops adding a second suffix:
    • CSA: AP CSA Full Course and Curriculum, Free | APCSExamPrep (54)
    • Cyber: AP Cybersecurity Full Course: All 5 Units, Free (47)
    • CSP (49) and Networking (56) are fine as they are.
    I could not check which queries these pages rank for, because the Ahrefs account is out of API units for the month. Read the two new titles as drafts and check them against Search Console before they go in.
  • Descriptions: Cyber needs one. For example: The full AP Cybersecurity course: 5 units of lessons, terminal labs, quizzes and unit exams, built for the May 5, 2027 exam. Free for students. (143). CSA needs its 54.5% sentence removed.
  • One visible H1 per hub, and Course markup on all four, describing only what is on the page. No ratings markup.
  • Links down, not across everything. Hub to units, units to lessons. 107 of the Cyber hub's 152 links go to individual exercises, quizzes, labs and unit exams. Those belong on its unit pages. That concentrates the hub's authority on five unit pages instead of spreading it over 150.
  • Links sideways at the top. Each hub's first screen links its own exam prep door, and the bottom links the other three courses in the body, not only in the footer. Networking finally links its practice exam and study guide. The CSP prep hub links back to the CSP course.
  • No handle changes. Class links in Canvas and other LMSs point at these URLs.
  • The biggest SEO lever here is not on these four pages: each course has 3 to 6 pages competing to be "the" page. /pages/ap-csa and /pages/ap-csp are empty but indexed, and Cyber has /pages/ap-cybersecurity-course, /pages/ap-cybersecurity and /pages/what-is-ap-cybersecurity alongside the hub. Redirecting or merging them is a handle decision, so it is yours.

Order of work

  1. Theme PR: templates/page.course-hub.json, a course-hub section, and one course facts snippet. Merging it changes no live page. Check it on a preview theme at 1920, 1440, 1366 and 390px.
  2. Networking first, the lowest-traffic hub (193 landings in 90 days): a one-row sheet sets the template and replaces the body's Times New Roman header with nothing, since the template draws the hero. Check it live.
  3. CSP, then CSA, each with its fact fixes in the same sheet so each body is overwritten once, not twice.
  4. Cyber last, since it has the most traffic (2,886) and the most links to move down to the unit pages. Its title and description go in with it.

Each sheet follows the usual rules: MERGE, one course per import, parsed back and diffed, and the post-import check run before and after. The check has to assert what was false before: one visible H1, the template's hero id present, no "54.5", the corrected unit weights, and no hidden page-title H1.

Three calls that are yours

  1. Template or body edits? I recommend the template. If you would rather keep hubs as pure page bodies, the fact fixes can ship this week as four sheets, but the full-width band will need the 100vw trick, and the drift problem stays.
  2. Ads on hubs. Board #419 wants side rails for ads. The CSA, CSP and Cyber hubs are on the theme's no-ads list today; Networking is not. A 1100px column leaves 170px rails at 1440px, room for a 160px skyscraper, and none at 1366px, which is a common school Chromebook width. The mockup uses the nav's 1200px so it lines up with the homepage.
  3. Timing. #419 said after the first weeks of school. The wrong CSA weights are live now, so I would not wait on the CSA facts even if the redesign waits.

How this was measured, and what was not

  • Each hub rendered in headless Chromium at 1440x900 and 390x844 on 2026-09-25. Bodies read from /pages/<handle>.json, full pages through lib/storefront-fetch.js.
  • All 238 unique internal links in the four bodies were requested: 234 answer 200, 3 are 301s (above), and the 404 is a Cloudflare email-protection link on the CSA page.
  • Traffic from Shopify analytics, sessions by landing page, referrer source and device type, last 90 days.
  • Not measured: search rankings and query data (Ahrefs out of units, no Search Console connection), real screen widths of visitors, and whether Raptive actually fills the Networking hub's ad slots.
  • The mockup is static HTML, not a Shopify render. Fonts and colours are the homepage's: navy #0c2340, yellow #ffc53d, Archivo headings, course colours CSA #2D6BC4, CSP #127968, Cyber #5b34b8, Networking #a14a07.
