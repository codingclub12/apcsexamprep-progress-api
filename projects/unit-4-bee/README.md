# Unit 4 project: The Hungry Bee

This is the existing "Greenfoot Basics #1 - The Hungry Bee" assignment, moved
here from the front of the course.

Its four tasks need instance variables (3.8), methods you write yourself (3.1
and 3.2), if statements (2.4), keyboard input (2.7) and touching another actor
(4.4). The last of those is lesson 4.4, which is why this is where it belongs.

Start from your Unit 3 file. By now the bee already flies and already has a
score field, so the new work is one method: `checkCollisionWithFlower()`.

## Before this ships

`displayScore()` uses `getWorld().showText(...)`, and `showText` appears in this
course only in lesson 6.7. Either teach it in 3.8, where the score first exists,
or drop `displayScore()` from this assignment. See `docs/intro-java-projects.md`.
