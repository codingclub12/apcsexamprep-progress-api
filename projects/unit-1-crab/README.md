# Unit 1 project: the crab

Open this scenario in Greenfoot and work through lessons 1.1 to 1.6 with it.

Nothing here is broken and nothing is missing. You are not filling in blanks
this unit; you are learning where everything is.

The only file you edit is `Crab.java`, and only in lesson 1.6, where you add
one or two lines to `act()`.

## What you should be able to do by the end

- Say what the world is and what an actor is, pointing at each on screen
- Create a new crab from the class diagram and drag it around
- Call `move`, `turn` and `setLocation` on it from the right-click menu
- Read a method signature in the documentation and say what it needs and what
  it hands back
- Put `move(2)` inside `act()`, compile, and press Run

If all six of those are true, you are ready for Unit 2, where you start writing
code into a file properly.
