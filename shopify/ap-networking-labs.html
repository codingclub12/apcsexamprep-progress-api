AP Networking Labs

Each AP Networking unit here has two labs. The unit lab is a project that runs across several class periods and ends with the piece of work that unit's performance task asks for. The topic lab is eight checks on a single topic.

All eight run inside the page. The networks, files and servers in them are simulated, so there is nothing to install and nothing real to break. The unit labs say what they need in one line, a browser, and they run on a Chromebook with no admin rights and no networking hardware. In a unit lab you work a terminal where ipconfig, ping, tracert, arp -a, nslookup and speedtest all answer from the simulated network, so the evidence you collect is the same every time you run it.

If a lab counts for a grade, sign in to your class before you start. The labs run either way, but your score saves to your gradebook only when you are signed in.

Lab 3: Segmented LAN Build

8 class periods. 8 checkpoints. A browser, no equipment.

One switch, and staff, students and guests who must not all reach each other. You assign every port to a segment, decide what may cross between segments, and prove the result with a reachability matrix before you document the design for the Unit 3 performance task.

Lab 4: Capture and Trace

8 class periods. 8 checkpoints. A browser, no equipment.

Topic lab

Move a File With SFTP

8 checks. Terminal practice.

A browser terminal, a simulated file server, and a site survey that has to end up on it. The last check is the one people skip: a transfer that printed no error is not proof the file arrived, but listing the folder you sent it to is.

A model, not a capture

The devices, addresses and command output in the unit labs were written for those labs. Real equipment is messier: timeouts vary, cables fail on and off, and output differs from one operating system to the next. What carries over is the reasoning, and that is the part being graded, here and on the exam. One practical note: tracert is the Windows spelling. On macOS and Linux the command is traceroute.

For teachers

Scores from the labs land in your class gradebook when students are signed in to your class. Students can work a lab as many times as they like; whether a retake replaces the recorded score follows the retry setting you chose for the class. Pacing and teacher materials for the whole course are in the AP Networking Command Center, and if you have not set up a class yet, start at the teacher class portal.
