Name the Thing

Give the repeated value a name, then let the change request decide whether you named the right ones

How to play: click a highlighted value to replace it with the named constant, and click again to put the raw value back. When you are done, apply the change request: the named value changes in one place, and every line that still hardcoded it breaks in front of you. Not every copy of a number is the same thing, so read what each one means.
