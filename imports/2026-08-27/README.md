## Read this before importing

**This sheet carries a `Body HTML` column.** The 2026-08-22 incident that blanked
a live student page was a sheet carrying `Body HTML`, and the SEO sheets in
`imports/2026-08-26/` are safe precisely because they have no content column.
This one is not in that category. It rewrites one live page body in full, MERGE
overwrites it, and Shopify keeps no undo.

So: one import, this sheet alone, and read the diff first if Matrixify offers a
dry run.

## Why it is safe to import

Every one of these is asserted by the generator before a row is written, and each
was re-checked independently against the generated CSV rather than trusted:

- no `ANSWERS`, `data-correct`, `data-val` or `data-answer` survives
- exactly one mount container, carrying `data-lesson="1.3"`
- exactly one mount script tag
- the unit nav rail and the activity nav are byte-identical to the original
- the JSON-LD schema block and the hero survive
- div open/close balance matches the original
